# BOTCAST Website v16

This is the complete standalone BOTCAST website, based on the approved v15 design.

## What's new in v16
- Added a dedicated Media section and navigation link.
- Integrated four animated GIFs from the BOTCAST marketing package:
  - Card combo
  - Radio tuning / Frequency Hopping
  - Broadcast in progress
  - Something is listening
- Added three optimized gameplay screenshots:
  - Broadcast console
  - Combo chain
  - Frequency Hopping
- GIFs animate inline; clicking a media item opens the original asset in a new tab.
- Responsive layout for desktop, tablet, and mobile.

## Files
- `index.html` — complete website
- `botcast-logo.svg` — BOTCAST logo
- `media/` — selected GIF and WebP media assets

## Run locally
Open `index.html` in a modern browser. The website is static and does not require a build step. Google Fonts are optional and have fallback fonts.

## Publish
Upload the contents of this folder to your hosting provider. The website has not been deployed to `botcastgame.com`; domain and hosting configuration are separate.
